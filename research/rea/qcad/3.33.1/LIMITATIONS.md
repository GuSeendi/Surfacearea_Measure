# Limitations

- Static package inventory does not establish runtime behavior.
- No application launch, user-data access, network capture or account sign-in was performed.
- REA 6.7.0 inventoried the DMG through a read-only mount but its extraction operation does not materialize DMG contents.
- No proprietary source, assets, credentials or license data are stored in this repository.
- QCAD public source is GPL-3.0 with optional exceptions. It was used to establish concepts and testable requirements only; no implementation code is copied into this project.
