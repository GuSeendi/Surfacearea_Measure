# Limitations

- No IPA, executable or application container was extracted.
- No decryption, DRM, signing, entitlement or platform-security bypass was attempted.
- A successful launch request does not establish that the application completed startup.
- Runtime attach was impossible because no stable target process was available; stock iOS would also require Gadget.
- No account/login action, UI automation, camera capture, project access, network capture or filesystem inspection was performed.
